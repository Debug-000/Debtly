# Contributing to Debtly

Debtly accepts contribution proposals, but the repository is not open source.

## Before You Contribute

- open an issue or discussion if you want to propose a larger change
- keep pull requests focused and easy to review
- do not introduce unrelated refactors in the same PR
- preserve the app's offline-first architecture and product direction

## Technical Expectations

- run `flutter analyze` before submitting changes
- test important flows on a real Android device when touching notifications
- add SQLite migrations when changing persisted schema
- keep UI work consistent with the existing design system
- avoid breaking existing local data behavior

## Licensing of Contributions

By submitting a pull request, patch, or other contribution to this repository,
you agree that:

- your contribution is submitted voluntarily
- you have the right to submit the contribution
- the project author may use, modify, relicense, publish, or reject the
  contribution
- you do not gain ownership of the project by contributing

## Reuse Policy

You may review the code and propose improvements, but you may not copy, reuse,
redistribute, or build another application from this codebase without prior
written permission from the author.
